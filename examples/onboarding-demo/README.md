# Учебные данные

Восемь настоящих UTF-8 TXT-карточек для будущего обучения Atom Search в HeroUI.
Это не рабочий Quickstart 0.1.1; набор не подключён к текущей сборке.
Ни DWG, ни других файлов с поддельным форматом нет.

«Пермские моторы» здесь — явно вымышленный учебный пример, а не материалы реальной
организации. Второй объект — вымышленный «Полярный музей». Содержимое всех карточек
придумано; рабочих документов, реквизитов и персональных данных нет.

Имена намеренно общие: «Спецификация», «Узлы примыкания», «График поставки».
Объект и раздел находятся в пути. Одинаковые названия в разных проектах помогают
учиться выбирать результат по его расположению, а не по условному номеру чертежа.

**Не смешивать с рабочим индексом.** Для уроков нужен отдельный временный индекс
и отдельный источник этого набора. Не добавляйте его в рабочие источники,
не объединяйте базы и не переносите учебные результаты в рабочий каталог.

## Прямой поиск: поддерживается ядром

Текущее ядро ищет буквальные слова по имени и относительному пути; для таких
уроков alias не нужен. Их `query_mode: literal_path` проверяется отдельно:

- «Пермские моторы» — только четыре файла с полным названием объекта в пути.
- «Пермские моторы зенитные фонари» — объект и раздел.
- «Полярный музей спецификация» — общее имя документа в другом проекте.
- «Пермские моторы график поставки» — выбор и показ файла в Проводнике.

`manifest.json`, версия 2, перечисляет пути, проекты и уроки.
`expected_files` с `expectation: top_results` означает первые N результатов,
без требования к порядку внутри этой группы; слабые совпадения ниже допустимы.
`selected_file` — цель действия пользователя. Фактический прогон прямых запросов
по этому набору выполняется отдельно; manifest не является отчётом об испытании.

## Сокращения: будущая возможность

**Разрешение alias пока не реализовано.** Словарь `project_aliases` — требование
для будущей итерации, а не работающая настройка. Уроки помечены
`required_capabilities: ["project_aliases"]` и должны быть заблокированы, пока
клиент не поддерживает эту возможность.

«ПМ» означает «Пермские моторы» только в области соответствующего проекта и
учебного источника. В том же источнике «ПМ» может означать «Полярный музей».
Без выбранного проекта нельзя расширять запрос молча: нужно предложить выбрать
объект. Урок `future_ambiguous_pm` требует этого выбора, а не выдачи всех проектов
или автоматического выбора первого alias.

## Ветвь, где есть только сокращение

`Учебный архив/Чёто до/Зенитные фонари ПМ/Пояснительная записка.txt`
намеренно не содержит полного названия «Пермские моторы» в пути. Проектный
`path_prefixes` связывает эту ветвь с учебным проектом `perm-motors`.

Прямой запрос «Пермские моторы» не должен добавлять эту карточку к буквальным
совпадениям. Буквальный поиск «ПМ» может найти сокращение в имени папки, но сам
по себе не устанавливает, какому проекту оно соответствует.

Будущий scoped alias-урок должен сначала разрешить проект и его обе ветви,
а затем искать «зенитные фонари» в этой области. Поэтому его ожидаемая группа
включает также пояснительную записку из сокращённого пути. Простая подстановка
полного названия в строку запроса этого результата не даст; это дополнительный
будущий случай, заблокированный capability `project_aliases`. При отсутствии
выбранного проекта неоднозначное «ПМ» по-прежнему требует выбора пользователя.

## Полное название тоже должно раскрывать сокращённые ветви

Будущий урок `future_full_project_to_short_branch` использует запрос
«Пермские моторы зенитные фонари» без предварительного выбора проекта.
Resolver должен распознать полное название, получить обе проектные ветви и
выполнить `project_scope_then_path_query` с остатком «зенитные фонари».
В ожидаемую группу входит также пояснительная записка из «Чёто до/Зенитные фонари ПМ».
Этот третий будущий урок пока заблокирован capability `project_aliases`.

Будущая интерактивная обучалка выбирает вариант урока по доступным capabilities
и использует реальный поисковый pipeline. Буквальные уроки проекта и раздела —
честный baseline 0.1.1; они имеют `disabled_when_capabilities: ["project_aliases"]`,
поскольку после включения resolver ожидаемая группа расширяется. Нельзя насильно
отключать resolver или подменять выдачу, чтобы подогнать её под старую literal-группу.
