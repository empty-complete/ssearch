# Локальная модель поиска

В поставку включается `Xenova/multilingual-e5-small`: ONNX-конвертация исходной
модели `intfloat/multilingual-e5-small`. Фиксированная версия и проверенные SHA256
находятся в `manifest.json`. Два бинарных файла занимают 135 390 915 байт
(около 129,12 MiB) и исключены из Git.

На машине сборки один раз выполнить из корня репозитория:

```powershell
.\.venv\Scripts\python.exe tools\fetch_model.py
```

Инструмент получает только два указанных в manifest файла с фиксированной версии,
проверяет длину и SHA256 и заменяет файл только после полной проверки. Для другого
каталога есть `--model-dir PATH`; туда также сохраняется manifest. Повторный запуск
использует проверенные локальные файлы. Незавершённая загрузка не заменяет старый
файл. Это инструмент подготовки поставки, он требует интернет только на машине
сборки. Приложение его не вызывает и ничего не скачивает.

## Контракт адаптера

`OnnxEmbedder(model_dir)` проверяет manifest и оба локальных файла один раз при
создании. Провайдер нужно переиспользовать для запросов и пакетной индексации.
Его `model_id` содержит версию и хеш весов: векторы разных версий смешивать нельзя.
`encode(texts, kind='passage')` возвращает нормализованные float32-векторы
размерности 384; для пользовательского запроса нужен `kind='query'`.

Исполнение использует только локальные `Tokenizer.from_file()` и ONNX Runtime
CPU, два вычислительных потока, не более 512 токенов на запись и пакеты до 32
записей. Для 3D-выхода применяются mean pooling по attention mask и
L2-нормализация; готовый 2D-выход тоже нормализуется. Паддинг берётся из реального
токенизатора. Телеметрия ONNX Runtime отключается доступным API. Если модель
отсутствует, повреждена или несовместима, адаптер поднимает `ModelUnavailable`;
вызывающий сервис продолжает лексический поиск.

В первой версии в модель передаются только названия и пути. Общий адаптер можно
использовать в AtomDB для будущих фрагментов документов без зависимости от Qt.

## Источники и лицензия

- [Версия ONNX-конвертации Xenova](https://huggingface.co/Xenova/multilingual-e5-small/tree/761b726dd34fb83930e26aab4e9ac3899aa1fa78).
- [README конвертации с указанием исходной модели](https://huggingface.co/Xenova/multilingual-e5-small/blob/761b726dd34fb83930e26aab4e9ac3899aa1fa78/README.md).
- [Настройки конвертации](https://huggingface.co/Xenova/multilingual-e5-small/blob/761b726dd34fb83930e26aab4e9ac3899aa1fa78/quant_config.json):
  `per_channel=true`, `reduce_range=true`, `QInt8`; исполнение на разных рабочих
  процессорах всё равно требует испытания.
- [Исходная модель и правила E5](https://huggingface.co/intfloat/multilingual-e5-small):
  MIT, префиксы `query: ` и `passage: `, masked mean pooling, L2, 512 токенов.
- [MIT-текст Microsoft UniLM](https://github.com/microsoft/unilm/blob/master/LICENSE)
  включён в `resources/licenses/model-MIT.txt`. Репозиторий Xenova указывает
  upstream, но собственного файла LICENSE и отдельного поля license не содержит.
  Уведомления о модели и конвертации должны сохраняться в поставке.

Контрольные суммы и размеры прочитаны из LFS pointers закреплённой версии
20 октября 2026 года. Скорость и качество на корпоративных именах файлов нельзя
считать проверенными до пилота на рабочих ПК.
