ssearch — Simple Search
Версия 0.2.0 · разрабатываемый кандидат для Windows

1. Возьмите проверенный ssearch-Setup-<version>.exe из GitHub Releases:
   https://github.com/empty-complete/ssearch/releases
   Установите для своей учётной записи; Python и отдельный сервер БД не нужны.
2. Откройте ssearch из меню «Пуск». В «Настройках» выберите рабочую папку.
3. Первое обновление большой папки и создание смыслового индекса занимают время.
   Окно остаётся доступным; обновление можно отменить и повторить позже.
4. Введите часть имени, номер или описание документа. Стрелками выберите
   результат и нажмите Enter либо щёлкните дважды: Проводник выделит файл.
5. «Обновить» запускает повторный обход. При переносе файла приложение
   попробует открыть ближайшую сохранившуюся родительскую папку.

Поиск, модель, база и справка работают локально. Доступ к сети нужен только для
сетевых источников. Сейчас поиск использует имена, пути и метаданные; содержимое
документов не читается. Текущая оболочка Qt; Electron ещё разрабатывается.
Автоматическое скачивание и применение обновлений ещё не реализованы.

Справка: кнопка «Справка» в приложении. MIT License и сторонние лицензии
доступны в «О программе», справке и файлах поставки, без обязательной EULA.

Индекс и настройки сохраняются в %LOCALAPPDATA%\AtomSearch для совместимости.
Обновление и обычное удаление программы не удаляют эти данные. При переходе
с Kaizen Search старый профиль переносится, только если целевой ещё пуст;
исходный профиль сохраняется. При ошибке закройте старую программу и повторите.

Windows 10 1809+ / Windows 11 x64 — целевые системы. GitHub CI не заменяет
отдельные проверки настоящей установки/native UI; Win10 проверяется в конце.
